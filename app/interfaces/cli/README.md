# cli

Interface de linha de comando.

## Responsabilidade

Fornece menus interativos para execucao local.

## Quando usar

Use para fluxos manuais simples. Novas operacoes complexas devem chamar os
mesmos servicos de dominio usados pela API e pela UI.

## Arquivos

- `context.py`: contexto compartilhado da CLI.
- `menus/`: menus por area.
