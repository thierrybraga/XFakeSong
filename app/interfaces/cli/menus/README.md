# menus

Menus da CLI.

## Responsabilidade

Agrupa telas textuais de dataset, treino, inferencia, resultados e configuracao.

## Quando usar

Use para alterar interacoes CLI. Codigo de processamento deve ficar no dominio.

## Arquivos

- `main_menu.py`: menu raiz.
- `dataset_menu.py`: datasets e features.
- `training_menu.py`: treino.
- `inference_menu.py`: inferencia.
- `other_menus.py`: resultados/configuracoes.
- `base_menu.py`: base comum.
