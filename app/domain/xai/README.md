# xai

Explicabilidade de modelos.

## Responsabilidade

Implementa Grad-CAM, SHAP e contrato de features tabulares para analises
interpretaveis.

## Quando usar

Use para explicar predicoes ou produzir material de auditoria/analise forense.

## Arquivos

- `gradcam.py`: Grad-CAM para modelos 1D/2D.
- `shap_explainer.py`: wrappers SHAP.
- `tabular.py`: descritores tabulares e contrato de interpretabilidade.
